# ملاحظات النشر والتشغيل

هذه الملاحظات تخص نشر التطبيق على Vercel مع قاعدة Neon. لا تضع أي أسرار أو
عناوين اتصال حقيقية في المستودع؛ استخدم متغيرات بيئة Vercel أو `.env.local`.

## متغيرات البيئة المطلوبة

| المتغير | القيمة |
| --- | --- |
| `APP_MODE` | `persistent` في الإنتاج |
| `DATABASE_URL` | عنوان Neon المجمّع الذي يحتوي مضيفه على `-pooler` |
| `BETTER_AUTH_SECRET` | مفتاح عشوائي قوي وثابت |
| `BETTER_AUTH_URL` | عنوان HTTPS الفعلي للتطبيق، وليس `http://localhost` |
| `NEXT_SERVER_ACTIONS_ENCRYPTION_KEY` | مفتاح ثابت 32 بايت بترميز base64 |

يمكن إنشاء مفتاح Server Actions من سطر الأوامر:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

لا تغيّر `NEXT_SERVER_ACTIONS_ENCRYPTION_KEY` بين النشرات. إذا تغيّر أو كان
مختلفًا بين نسخ النشر، فقد تفشل طلبات الكتابة من صفحات قديمة برسالة تشبه
«Server Action not found». بعد كل نشر يُنصح بتحديث الصفحة تحديثًا كاملًا، وعدم
الاعتماد على نسخة مخبأة من التطبيق.

## قاعدة البيانات

1. خذ نسخة احتياطية قبل تطبيق أي ترحيل على قاعدة الإنتاج.
2. راجع ملفات `drizzle/*.sql` قبل التطبيق.
3. طبّق الترحيلات بأمر `npm run db:migrate` مع `DATABASE_URL` الصحيح.
4. تأكد من تطبيق الترحيلات `0028` و`0029` و`0030` قبل نشر شاشات المصاريف
   والأصناف الجديدة.

الترحيلات `0029` و`0030` توحّد اسم وسعر صنف الكانتين بين المخزون وأصناف البيع،
وربط صفوف البيع القديمة بأصناف المخزون. الترحيلات لا تعيد كتابة أسطر الفواتير
التاريخية؛ سعر الفاتورة يبقى كما حُفظ وقت إنشائها.

## بعد النشر

- سجّل الدخول بحساب مسؤول وتأكد من نجاح عمليات الكتابة: إضافة مصروف عهدة،
  تعديل حركة عهدة، تعديل صنف كانتين، وإنشاء فاتورة بيع.
- تحقق من أن تعديل صنف البيع يحدّث صنف المخزون، والعكس، بعد إعادة تحميل الصفحة.
- جرّب طباعة سجل واحد وتأكد من عدم تكرار الصفحات أو العناصر.
- راجع سجل التدقيق للتأكد من تسجيل اسم المنفذ ونوع الإجراء.

## ترحيل بيانات البوابة (الإصدار 4.8)

قبل نشر الإصدار 4.8 على قاعدة Neon الحالية، طبّق الترحيل
`drizzle/0032_gate_visitor_details.sql` باستخدام `npm run db:migrate` بعد
ضبط `DATABASE_URL` على قاعدة الإنتاج الصحيحة. يضيف الترحيل أعمدة الوظيفة
وبيانات السيارة التي يقرأها التطبيق عند تحميل بيانات البوابة؛ نشر الكود دون
الترحيل قد يؤدي إلى خطأ خادم عند فتح التطبيق. خذ نسخة احتياطية أولًا، ثم
أعد النشر أو أعد تحميل الموقع بعد نجاح الترحيل.
